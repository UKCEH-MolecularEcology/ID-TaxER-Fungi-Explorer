# ID-TaxER Fungi Explorer

**ID-TaxER Fungi Explorer** provides an interface to visualise potential soil habitat preferences of fungal taxa derived from high-throughput sequencing data (ITS2). Users can query a database of sequences derived from a large soil survey conducted across Britain (the Countryside Survey), using either a query sequence or taconomic name. Each taxa in the database is linked to taxonomic assignments alongside environmental (pH and habitat) preferences and a geospatial distribution (currently Britain only).
